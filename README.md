# Tu Tiên Lục

Game nhập vai tu tiên bằng chữ, chạy hoàn toàn trên trình duyệt. Không cần mạng, không cần AI.

## Chơi
- Trên web: mở trang GitHub Pages của repo này.
- Offline: tải repo về (Code → Download ZIP), giải nén, mở `index.html`.

## Cấu trúc
- `index.html`: toàn bộ game (code + lời kể + hình nhân vật, yêu thú, bối cảnh).
- `gear_atlas.webp`: bảng icon trang bị, pháp bảo, khí linh.

## Nhân vật nữ ghép lớp (v8.2)
Ảnh nhân vật nữ được ghép từ nhiều lớp trong thư mục `doll/` (khuôn mặt, tóc, trang phục…). Công cụ tách lớp nằm ở `tools/build_doll.py`.
